# 通用战斗规则

现行来源为《通用战斗规则》Drive 文档；来源映射与适用优先级见 [00_CURRENT_SPEC_SOURCES.md](00_CURRENT_SPEC_SOURCES.md)。角色、Boss、模式或特殊状态的明确说明优先于本文件。

## 1. 适用原则与初始值

本文件适用于没有特殊说明的普通战斗、单位、技能与状态。角色、Boss、技能、模式或特殊状态的明确规则优先。

“原攻击力”是单位进入战斗时的攻击力。战斗开始时，护盾、能量、「势」「意」「法」、增伤、减伤均为 0；不持有 buff/debuff；暴击率为 0%，暴击伤害为 50%。生命、护盾、攻击力、速度、暴击率、体系机制值和特殊层数最低为 0；能量无上限，非主动支付可使能量为负数，主动支付不得使能量低于 0。

伤害、治疗、护盾的最终结果四舍五入并保留 1 位小数；体系机制值、能量和特殊层数最终四舍五入取整；多步计算只在最终结果取整，最终伤害最低为 0。

## 2. 编成与站位

- 队伍最多 4 名角色，位置为前1、前2、后1、后2。
- 前1对应后1，前2对应后2。
- 后排只检查同编号前排。对应前排有角色时，后排受到伤害减少 50%，属于普通减伤乘区。
- 其他前排位置不能替代对应位置；对应前排死亡或离场后立即失去该减伤。

## 3. 行动序列、个人回合与行动

每个行动序列开始时读取所有在场单位当前速度并按从高到低排序；排序后速度变化只影响下一个序列。速度相同时，玩家角色优先敌方；玩家角色按前1、前2、后1、后2，敌方按登场先后排序。

单位依次获得个人回合，最后一名结束后开始新序列并重新排序。默认释放一次技能后结束个人回合。没有技能或其他效果结算时，玩家可主动结束回合，该操作不计入行动但正常进入回合结束。

释放一次技能通常计为一次行动。标注“不计入行动”的技能不触发行动后效果，也不创建新的行动后结算链。标注“不结束回合”或允许多次使用的技能可在同一回合产生多次行动。多分支技能默认由玩家释放时选择一个分支。

## 4. 触发、持续与特殊回合

同一时点默认顺序为：单位自身被动 -> 体系共通效果 -> 其他效果按获得时间顺序。行动后固定为：自身被动 -> 体系共通效果 -> 当前技能描述中的行动后效果 -> 其他行动后效果 -> 判断回合是否结束；每个效果执行时按实时状态重新检查条件。

“持续 N 回合”立即生效，从当前个人回合计为第 1 回合；持续 1 回合在当前回合结束消失，持续 2 回合在下一个自身回合结束消失。按行动序列计时会明确写作“持续 N 序列”。每层可叠加状态独立计时，结束时点相同的层可以合并记录。自身回合之外获得的“持续 N 回合”从何时计数，尚未规定。

额外回合在当前回合完整结束后立即开始，属于完整回合，可继续产生额外回合且默认无次数上限。“跳过回合”完全不触发回合开始、行动或回合结束。中途入场与复活的单位均从下一个行动序列加入排序。

## 5. 资源与技能支付

手动技能释放前必须拥有全部所需资源，任何一种不足即禁用；自动技能只需满足触发条件。

所有有资源消耗的技能遵循固定流程：

1. 检查所需资源。
2. 预留本次消耗。
3. 完整结算技能全部效果。
4. 实际支付资源。

被免除、阻止或未实际发生的消耗不视为消耗，也不触发“消耗资源时”效果。“将能量设为某数值”是直接设定，不是获得或消耗。

## 6. 普通、额外与特殊伤害

普通技能默认基础伤害为当前攻击力乘技能倍率。普通伤害公式为：

`基础伤害 × 暴击乘区 × 各增伤乘区 × 各减伤乘区`

暴击时乘以 `1 + 当前暴击伤害`；暴击率最高按 100% 判定。同名增伤/减伤在同一乘区相加，不同名乘区相乘；任一减伤乘区合计达到或超过 100% 时该乘区系数为 0。结算顺序为基础伤害 -> 暴击 -> 增伤 -> 减伤 -> 保留 1 位小数 -> 扣护盾与生命。

额外伤害不算攻击，不能暴击、无视护盾、不受普通增伤/减伤影响，但可受额外伤害专属修正。若触发它的攻击已使目标死亡并移除，依附的未结算额外伤害取消。特殊伤害默认先扣护盾再扣生命；能否暴击、受何种增减伤影响必须以技能说明为准，尚无统一通则。

“受到攻击”按攻击行为判断，即使伤害为 0 或完全被护盾吸收仍成立；“受到伤害”包含护盾吸收部分；“失去生命值”只算实际生命减少。技能写作“造成伤害 N 次”即 N 次独立攻击：每次独立判暴击与攻击触发。标注每技能最多一次的效果默认第一次攻击触发。单体目标中途移除则停止剩余攻击且默认不换目标；群体攻击继续处理其他存活目标；随机目标在每次攻击前从当前存活合法目标重新选择。

## 7. 护盾、治疗、死亡与状态

护盾统一累加。有限生命单位的护盾上限是最大生命的 2 倍；无限生命单位不受该上限。普通伤害和特殊伤害先扣护盾，溢出再扣生命。即使护盾已达上限，“获得护盾”动作仍发生并可触发相关效果，除非条件明确要求实际获得值大于 0。治疗默认不超过最大生命，除非明确有溢出用途。

生命降至 0 时死亡并移除。若单位在自身技能中降至 0，先完整结算该技能再移除，之后不结算其行动后或回合结束。移除后除明确死亡效果外不再触发后续效果；当前行动序列中的位置保留为空位，轮到时直接跳过。

同名 buff、debuff、持续状态默认可叠加，各层独立计时。净化 1 层 debuff 时优先最早可净化层；最早层不可净化则跳过；同时获得且不可区分时随机移除 1 层。普通属性降低、持续伤害、控制、体系负面状态默认可净化，明确不可净化者除外。「势」「意」「法」「势压」「海潮」「春华」「秋实」、领域及其他明确特殊状态默认不能被普通驱散，必须明确点名才能移除。施加者死亡/离场后普通状态保留，只有标为与施加者绑定的状态才一同移除。

## 8. 体系共通规则

### 8.1 「势」与「势压」

「势」无上限，每层提供 1 点攻击力；通过「势」获得的攻击力加成最高为原攻击力的 2 倍。个人回合开始时，若该攻击力加成已到上限，每完整 10 层「势」获得 1 层「势压」。获得「势压」时每层给 5 点体系共通护盾，不属于角色自身技能/被动护盾。攻击时每层「势压」造成 3 点额外伤害；每个技能最多触发一次，默认第一次攻击触发，第一次为群体攻击时对每个目标各触发一次。个人回合结束失去全部「势压」。

### 8.2 「意」与「法」

「意」无上限，每个个人回合结束失去 1 层。持有至少 1 层时暴击率加 30%，不随层数叠加；每次计入行动的技能完整结算后，在体系共通效果阶段若仍持有「意」，有 50% 概率获得 1 点能量。不计入行动的技能不触发此效果。

「法」无上限，本身没有通用被动效果；「法」体系角色可按其技能说明消耗「法」强化技能。

## 9. 战斗结束与训练例外

普通战斗中，所有敌方死亡为玩家胜利，所有己方死亡为玩家失败。满足条件后完成当前技能与本次死亡直接产生的死亡效果，立即结束战斗，不再触发行动后、回合结束、延迟效果或额外回合。

训练模式例外：击败有限生命 Boss 后结束训练；无限生命 Boss 不能被击败，只能主动退出。所有玩家角色死亡不判定失败，而是立即暂停并展示战斗数据，暂停期间 Boss 不再行动，玩家只能重置或退出。重置恢复全部战斗状态并立即重开。无限生命单位正常显示受伤但生命不减少，免疫直接死亡和设为 0 生命，护盾无最大生命 2 倍上限。

## 10. 信息显示与未定边界

生命显示“当前生命／最大生命”，护盾独立显示；当前攻击力在战斗显示，原攻击力在详情显示；角色只显示自身体系变量；状态显示名称或图标、层数、持续时间和完整说明；数值最多显示 1 位小数。

未定：自身回合外获得持续 N 回合的计时起点；特殊伤害的统一暴击/增减伤规则；除 debuff 净化外，同一时点且获得顺序完全相同的普通触发效果的先后。

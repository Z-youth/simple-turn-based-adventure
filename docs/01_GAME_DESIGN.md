# 《简单的回合制大冒险》游戏设计规格

## 1. 规则基准与优先级

现行来源、适用范围和优先级见 [00_CURRENT_SPEC_SOURCES.md](00_CURRENT_SPEC_SOURCES.md)。本文件只汇总《游戏流程》已经确定的总体路径；战斗、角色和 Boss 的细则分别服从对应专题规格。

## 2. 项目定位

《简单的回合制大冒险》是浏览器运行的原创回合制战斗测试版，用于验证战斗逻辑、行动顺序、技能交互、资源系统与战斗反馈。当前优先制作训练模式；挑战模式入口已存在，但没有形成可执行规则。

## 3. 总体流程

已确定的主流程为：

`初始界面 -> 模式选择 -> 角色与站位配置 -> Boss 选择 -> 正式战斗`

各阶段必须按此顺序完成。当前没有跳过阶段直接进入后续阶段的规则。

### 3.1 初始界面

- 正上方显示游戏名《简单的回合制大冒险》。
- 中部提供“开始游戏”与“退出游戏”。
- 选择开始游戏后进入模式选择。
- 选择“退出游戏”时必须二次确认；确认后结束当前游戏状态并停留在初始界面，网页版不关闭浏览器窗口。

### 3.2 模式选择

- 入口包含训练模式与挑战模式。
- 当前优先制作训练模式。
- 训练模式进入角色与站位配置。
- 挑战模式当前不进入后续配置或战斗；点击后仅在界面最上方显示“开发中，不要再点啦！”，持续 1.5 秒。再次点击重新触发并重新计时。

### 3.3 角色与站位配置

- 训练模式队伍选择 1 至 4 名角色，同一角色不可重复选择；站位为前1、前2、后1、后2，每个站位只能配置 1 名角色。
- 角色选择与站位配置在同一页面完成，可返回模式选择；Boss 选择页可返回该页面修改队伍。
- 完成配置后进入 Boss 选择。

### 3.4 Boss 选择与初始化

- 每次战斗选择 1 名 Boss。
- 训练模式可以选择全部已开放角色和全部已开放 Boss。
- 选择完成后：读取模式、角色、站位和 Boss，初始化战斗状态，开始第一个行动序列。
- 点击“开始战斗”后直接进入正式战斗，不进行最终确认。
- Boss 选择界面是否显示属性、技能、推荐队伍、难度或生命类型标记，尚未明确。

## 4. 正式战斗与训练流程

战斗由连续行动序列推动，直到进入当前模式的结束、暂停或退出分支。行动、结算、胜负和角色/Boss 规则分别以 `03_COMBAT_RULES.md` 与 `04_CONTENT_SPEC.md` 为准。

### 4.1 训练模式

- 训练模式用于自由选择已开放角色和 Boss 并测试战斗。
- 击败有限生命 Boss 后进入战斗结果页。结果页显示行动序列数、每个行动序列总伤害、各角色总伤害、总承伤、总给予护盾和总治疗，并提供重新开始与退出战斗。
- 无限生命 Boss 不能通过击败结束，只能主动退出。
- 所有玩家角色死亡时，不判定普通失败；立即暂停战斗、展示本次战斗数据，Boss 不再行动。
- 手动暂停后可继续游戏、查看完整战斗日志或返回战场；全员死亡自动暂停时隐藏或禁用继续游戏。
- 暂停菜单可“结束战斗”，使本次训练判定为失败并进入战斗结果页；结果页显示与有限生命 Boss 结束相同的统计和操作。
- 重置恢复全部战斗状态，并沿用本次选择的角色、站位和 Boss 立即重新开始；主动退出会暂停并弹出确认，确认后返回模式选择，取消后保持暂停并显示操作菜单。

### 4.2 已知的未定流程边界

- Boss 选择界面展示哪些信息。
- 挑战模式的角色限制、Boss/关卡选择、胜负去向、奖励、进度、次数、难度与解锁。

## 5. 内容现状

- 正式记录的可玩角色：王大海、严岩、李木头，均属于「势」体系。
- 严岩和李木头即使尚未实现，仍是正式规则内容。
- 当前唯一正式记录的 Boss 是无限生命的训练假人。
- 「意」与「法」体系存在通用规则，但尚无具体角色实例。

## 6. 不得推定的设计

当前没有角色职业、推荐站位、稀有度、装备、成长、冷却时间、组合技能或同体系组队加成规则；也没有挑战模式、其他 Boss、奖励、解锁、剧情、美术或音频的已定规则。上述内容均不得作为实现或验收前提。

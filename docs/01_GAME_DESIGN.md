# 《简单的回合制大冒险》游戏设计规格

## 1. 项目定位

本项目是浏览器运行的原创回合制战斗测试版，用于验证战斗逻辑、行动顺序、技能交互、资源系统和战斗反馈。当前优先完善训练模式；正式挑战模式只有入口提示，关卡、奖励、进度、难度、次数和解锁均未设计。

规则来源与优先级见 [00_CURRENT_SPEC_SOURCES.md](00_CURRENT_SPEC_SOURCES.md)。

## 2. 总体流程

现行主流程固定为：

`初始界面 → 模式选择 → 角色与站位配置 → Boss 选择 → 正式战斗`

- 初始界面显示游戏名，以及“开始游戏”“退出游戏”；退出需要二次确认，网页版确认后停留在初始界面，不关闭浏览器。
- 模式选择包含训练模式与挑战模式。挑战模式点击后只在顶部显示“开发中，不要再点啦！”1.5 秒，再次点击重新触发并计时。
- 训练模式可选全部已开放角色与 Boss。队伍选择 1～4 名不重复角色，配置前1、前2、后1、后2四个不可重复站位；角色与站位在同页配置。
- Boss 选择页可返回队伍配置；每次选择 1 名 Boss。点击“开始战斗”后直接初始化，不增加最终确认。
- 初始化依次读取模式、角色、站位和 Boss，初始化单位、资源、状态与战斗变量，结算战斗开始效果，再进入第一个行动序列。

Boss 选择页具体显示哪些属性、技能、推荐队伍、难度或生命类型仍未明确。

## 3. 战斗与训练流程

战斗由连续行动序列推进：

`初始化 → 战斗开始效果 → 序列开始 → 读取速度并排序 → 各单位个人回合 → 序列结束 → 下一序列`

个人回合包含回合开始、行动选择、行动开始、技能执行、行动后、回合结束和额外回合检查。完整生命周期、深度优先触发链、持续时间、资源预留与支付、延迟队列、重复释放、目标失效、死亡和结束截止点见 `03_COMBAT_RULES.md`；角色、Boss 的专属插入点和阶段替换见 `04_CONTENT_SPEC.md`。

训练中可能进入：

- 正常击败有限生命 Boss 并进入结果页。
- 手动暂停，查看战场、完整日志和统计，继续或确认结束战斗。
- 玩家全灭后自动暂停，不判定普通失败，且不能继续，只能重置或退出。
- 重置全部战斗状态，沿用当前队伍、站位和 Boss 立即重开。
- 主动退出时暂停并确认；确认后返回模式选择，取消后保持暂停并显示操作菜单。

结果页显示行动序列数、每个序列总伤害，以及各角色总伤害、总承伤、总给予护盾和总治疗；可用当前选择立即重开或退出。

## 4. 现行角色与 Boss

正式规格包含四名可玩角色，全部属于「势」体系：

- 王大海：连续行动、快速积势与自动群体攻击。
- 严岩：受击蓄势、消耗势生成护盾与全队保护。
- 李木头：势层数转换、延迟收益、刀域与多次攻击。
- 流年：队友势联动、流转交换、领域、延迟队列与重复释放。

正式规格包含两名可选 Boss：

- 训练假人：无限生命基础测试 Boss。
- 万夫长：有限生命、多阶段、多单位 Boss；一阶段主体为骸骨将军并召唤尸卒，二阶段主体为万夫长并使用两名不化王骑。

骸骨将军与万夫长是同一 Boss 的阶段主体替换，不是两名可同时选择的 Boss。击败骸骨将军只触发阶段转换；仅最终击败二阶段万夫长才胜利。

## 5. 战场与反馈

- 玩家位置不自动重排：右上/右下为前1/前2，左上/左下为后1/后2，空位保持为空。
- 默认卡片显示名称、生命条和当前/最大生命；悬停显示当前攻击、增伤、减伤、护盾、暴击、资源、势、状态和专属变量。
- 流年显示「流」和「三生流转」开关，「流转」按特殊 buff 显示；李木头显示刀域；王大海显示海潮。
- 有限生命单位护盾外壳比例为 `当前护盾 /（最大生命 × 2）`；无限生命且无护盾上限的单位不显示该外壳。
- 战斗事件只显示真实行动与独立触发，名称、来源和目标取自引擎原始事件；内部生命周期事件不显示。
- 受到实际伤害时卡片抖动并变红 0.9 秒，多段伤害重新触发。每次角色或 Boss 行动完成后延迟 1 秒再推进或开放操作，但不改变结算。

## 6. 明确未设计内容

不得自行补充正式挑战模式、其他角色或 Boss、成长、装备、稀有度、职业、养成、正式美术、音频或剧情。除万夫长专属多单位规则外，一场战斗能否选择多个 Boss 也未形成通用规则。

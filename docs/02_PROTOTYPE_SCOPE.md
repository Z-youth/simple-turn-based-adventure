# 测试版范围规格

## 1. 现阶段目标

阶段 0 只同步现行规格，不实现游戏。后续开发目标是把基线中的训练战斗扩展为能够验证四名角色、多敌人、召唤、协击、有限生命多阶段 Boss 和完整战斗生命周期的版本。

“纳入现阶段规格”不代表当前代码已经完成；实际实施顺序见 `05_IMPLEMENTATION_PLAN.md`。

## 2. 已纳入正式规格

- 训练模式完整流程：初始界面、模式选择、1～4 名角色和站位配置、选择 1 名 Boss、战斗、暂停、重置、退出和结果页。
- 四名角色：王大海、严岩、李木头、流年。
- 两名 Boss：无限生命训练假人；有限生命、多阶段的万夫长。
- 万夫长战斗单位：一阶段骸骨将军、最多 5 名尸卒；二阶段万夫长、上方和下方各 1 名不化王骑。
- 多个敌方单位同时在场、敌方登场先后排序、存活合法目标池、中心/上方/下方位置。
- 动态召唤、召唤后的即时完整个人回合、下序列入队、清除、暂时退场、恢复登场与永久死亡。
- 普通伤害及允许分摊的特殊伤害入口、协击、群体/随机/前排优先目标。
- Boss 主体阶段替换、转换演出、队列位置失效、固定目标失效、跨阶段保存与清理。
- 战斗开始效果、完整个人回合阶段、深度优先即时触发链、持续时间、资源检查/预留/支付、额外行动/额外回合、不计行动技能、延迟队列和重复释放。
- 训练模式有限/无限生命结束规则、玩家全灭暂停、统计、重置和退出。

## 3. 当前代码基线与后续新增

基线 `a315205` 已有王大海、严岩、李木头、训练假人和训练流程。流年、万夫长、多单位战场、召唤、阶段替换、跨阶段保存以及新版通用结算能力属于已确认规格，但必须依 `05_IMPLEMENTATION_PLAN.md` 分阶段实施，不能在阶段 0 修改代码。

## 4. 训练结束边界

| 情况 | 结果 |
| --- | --- |
| 有限生命 Boss 被最终击败 | 完成当前技能及直接死亡效果后立即胜利并进入结果页 |
| 骸骨将军生命归零 | 不胜利、不普通死亡；当前行动与触发链结束后进入二阶段 |
| 无限生命训练假人受伤 | 显示伤害但生命不减少，不能通过击败结束 |
| 玩家全灭 | 完成当前技能及直接效果后自动暂停，不触发后续行动后、协击、额外行动或独立行动 |
| 手动结束战斗 | 确认后判定本次训练失败并进入结果页 |

## 5. 明确不在当前规格内

- 正式挑战模式的角色限制、Boss/关卡选择、连续战斗、胜负去向、奖励、进度、次数、难度和解锁。
- 其他训练 Boss、Boss 狂暴、通用技能冷却、通用 AI 选择逻辑、难度和奖励。
- 未确认的其他角色、Boss、体系、组合技能或固定同体系组队加成。
- 角色职业、推荐站位、稀有度、装备、成长、升级、剧情、正式美术和音频。
- 把万夫长专属多单位与召唤规则扩展为“可选择多个 Boss”的通用编成规则。

通用规则见 `03_COMBAT_RULES.md`，专属内容见 `04_CONTENT_SPEC.md`。专属规则覆盖通则；未明确之处不得从旧代码或旧文档补写。

# 测试版范围（PROTOTYPE_SCOPE）


版本：V0 完整训练模式测试版
目标：不以最小工作量为目标，以完整、稳定、可验证地实现已定功能为目标，用于观察 Codex CLI 在真实小型游戏项目中的开发能力。


## 1. 完成定义


V0 只有在以下条件同时满足时才算完成：
- 玩家可以从标题界面顺畅走完整个流程并进入战斗。
- 王大海、严岩、训练假人的全部已定机制正确实现。
- 站位、行动序列、状态、护盾、伤害与资源规则符合《战斗规则》。
- 训练可主动结束，玩家全灭可自动失败，并展示统计。
- 页面刷新、返回、重置、重复开局不会产生脏状态。
- 核心规则具有自动测试。
- npm run test、npm run lint、npm run build 全部通过。
- 不存在已知的无限触发、重复结算、死循环或阻塞操作问题。


## 2. 必做流程


### 2.1 标题界面
- 显示游戏名《简单的回合制大冒险》。
- “开始游戏”进入模式选择。
- “退出游戏”在浏览器环境中显示无法直接关闭网页的提示，并提供返回。


### 2.2 模式选择
- 训练模式可选择并进入。
- 挑战模式显示“暂未开放”，保持禁用或点击后提示。
- 可返回标题界面。


### 2.3 角色选择
- 展示王大海与严岩的角色卡片。
- 卡片显示体系、生命、攻击力、速度、技能概要。
- 至少选择 1 人，最多选择 4 人。
- 不允许重复角色。
- 当前仅有 2 名角色，因此正常可组成单人或双人队。
- 可移除已选角色并返回上一步。


### 2.4 站位编排
- 展示前1、前2、后1、后2四个独立位置。
- 支持把已选角色放置、交换、移除。
- 允许任意空位和仅后排出战。
- 清晰显示前1保护后1、前2保护后2的对应关系。
- 未放置全部已选角色时不可继续。


### 2.5 Boss 选择
- 展示训练假人卡片与其属性、回合逻辑和无限生命说明。
- 选择后可开始战斗。
- 可返回并保留或明确重置前一步选择。


## 3. 必做战斗界面


### 3.1 战场信息
- 玩家四个站位与 Boss 区域。
- 每个单位显示姓名、存活状态、生命、护盾、能量、攻击力、速度、暴击率、暴伤。
- 「势」「势压」「海潮」等特殊变量可见。
- Buff 与 Debuff 显示总层数，并可查看不同计时批次。
- 后排保护生效时有清晰标识。


### 3.2 时序信息
- 显示当前行动序列编号。
- 显示本行动序列的排序队列。
- 明确标记当前个人回合单位。
- 显示当前阶段，如技能选择、目标选择、确认、结算、暂停。


### 3.3 玩家操作
- 技能按钮根据资源、锁定与目标合法性正确启用或禁用。
- 多分支技能先选择分支。
- 单体技能进入目标选择。
- 最终确认前可取消技能、分支或目标选择。
- 点击“确认释放”后才触发行动并支付资源。
- 始终提供“结束回合”。仍存在合法行动时点击需二次确认；无合法行动时直接结束。


### 3.4 反馈
- 战斗日志记录回合开始、行动、技能、资源变化、伤害、暴击、护盾、状态、死亡和训练结束。
- 普通伤害、额外伤害、护盾吸收和生命损失应可区分。
- 提供简洁的伤害数字、护盾数字、状态提示与当前行动高亮。
- 正式角色动画和素材不是 V0 必需品，可使用色块、文字和基础 CSS 动效。


### 3.5 战斗控制
- 暂停与继续。
- 重置当前训练，回到相同编队与 Boss 的初始状态。
- 退出战斗，确认后返回适当页面。
- 主动结束训练，确认后进入统计页。


## 4. 训练结束与统计


训练假人不会死亡，因此不存在击杀 Boss 的胜利。


结果类型：
- 主动结束：显示“训练结束”，不算胜利或失败。
- 全体玩家死亡：显示“训练失败”。


统计至少包括：
- 总普通伤害。
- 总额外伤害。
- 总承受伤害。
- 总护盾获得量。
- 各角色行动次数。
- 各技能释放次数。
- 各角色最高「势」层数。
- 完成的行动序列数。


结果页支持重新训练和返回模式选择或标题界面。


## 5. 必做内容


角色：
- 王大海。
- 严岩。


Boss：
- 训练假人。


体系：
- 完整实现「势」与「势压」。
- 「意」「法」保留数据设计说明，不要求可玩内容。


系统：
- 行动序列与速度排序。
- 行动、个人回合、回合开始和回合结束。
- 同一回合多次行动。
- 分支技能、自动技能与非行动技能。
- 普通伤害、护盾值伤害、额外伤害。
- 护盾、Buff、Debuff、独立批次持续时间。
- 暴击与暴击率溢出。
- 能量与资源支付。
- 死亡、随机目标、训练统计。


## 6. 暂不实现


- 挑战模式实际内容。
- 王大海、严岩以外的角色。
- 训练假人以外的 Boss 或召唤物。
- 「意」「法」可玩角色。
- 装备、道具、养成、关卡、剧情、存档与联网。
- 正式美术、Live2D、3D、复杂粒子、配音与完整音乐。
- 复活、追击、反击、协同攻击、额外回合、控制、命中与闪避。


这些内容不得阻塞 V0，但实现时避免把核心引擎写死到只能支持当前两个角色。


## 7. 质量要求


- 纯战斗逻辑不得读取或操作 DOM。
- React 只负责展示状态与派发明确指令。
- 角色、技能、Boss 和状态尽量数据驱动。
- 随机数通过可注入接口使用，测试可固定随机种子或序列。
- 每个复杂技能都要有针对结算顺序的测试。
- UI 在常见桌面浏览器尺寸下无关键内容溢出。
- 所有按钮有禁用状态、返回路径和必要确认。
- 错误不应静默吞掉，应在开发日志或界面给出可诊断信息。

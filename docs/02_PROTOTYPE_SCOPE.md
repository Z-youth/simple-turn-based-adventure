# 测试版范围规格

## 1. 现阶段目标

本测试版用于验证已确定的回合制战斗规则。当前完整可执行的战斗模式只有训练模式；挑战模式的后续流程仍未设计，但其模式选择入口和“开发中，不要再点啦！”1.5 秒提示属于已确定界面行为。

## 2. 已确定的训练范围

- 初始界面、模式选择、角色与站位配置、单个 Boss 选择和正式战斗的顺序，以及初始界面退出的二次确认。
- 训练模式 1 至 4 名角色、角色与站位同页配置、角色与站位均不可重复，以及前1、前2、后1、后2站位。
- 全部已开放角色和 Boss 可在训练模式中选择。
- 连续行动序列、角色个人回合、自动/手动技能、伤害、护盾、状态、体系变量与死亡移除。
- 已正式记录的角色王大海、严岩、李木头，以及训练假人 Boss。
- 训练中的有限生命 Boss 结束、无限生命 Boss 主动退出、全员死亡暂停、数据展示、重置和退出流程。

## 3. 训练结束与控制

| 情况 | 结果 |
| --- | --- |
| 有限生命 Boss 被击败 | 进入结果页，展示行动序列数、序列总伤害、各角色总伤害/承伤/护盾/治疗；可重新开始或退出。 |
| 无限生命 Boss 受到伤害 | 正常显示伤害，但生命不减少，不能由击败结束。 |
| 所有玩家角色死亡 | 暂停并展示本次战斗数据，不判定普通失败；Boss 不再行动。 |
| 全员死亡后的操作 | 自动暂停时隐藏或禁用继续游戏；可重置或退出。 |
| 重置 | 恢复所有战斗状态，保留本次角色、站位和 Boss，立即重新开始。 |
| 主动退出 | 暂停，确认后返回模式选择。 |

## 4. 信息显示的已定要求

- 生命显示为“当前生命／最大生命”，护盾独立显示。
- 战斗中显示当前攻击力；详情同时显示原攻击力。
- 角色只显示自身体系变量。
- buff、debuff 显示名称或图标、层数、剩余持续时间与完整效果说明。
- 百分比和属性数值最多显示 1 位小数；整数不显示多余 `.0`。

## 5. 已确定的战斗界面与反馈

- 战场不自动重排：玩家单位固定使用战前选择的前1、前2、后1、后2位置，空位保持为空；右侧为前排，右上为前1、右下为前2、左上为后1、左下为后2。
- 单位卡默认显示名称、生命条和“当前生命/最大生命”；悬停详情显示当前攻击、增伤、减伤、护盾、暴击率、暴击伤害、实际拥有的资源或势，以及状态与专属变量。详情区可滚动，状态按“名称+数值（层数），持续剩余时间”显示。
- 技能悬停详情必须基于真实规则显示资源、伤害公式或倍率、命中段数、护盾/治疗、状态、目标规则与条件效果。
- 有限生命单位的护盾外壳比例为“当前护盾/(最大生命×2)”，护盾为 0 时不显示；无限生命单位不显示该外壳。
- 事件窗口只显示真实行动与独立触发。行动从开始到结束合并为一条实时记录；来源不同的动作不得合并。角色名、技能名、触发名、来源和目标必须来自引擎原始事件。
- 状态到期、层数减少、临时属性倒计时、资源直接设置、势压重置等内部/生命周期事件不进入事件窗口。势压仅在存在实际额外伤害时显示一条含该伤害的记录。
- 实际受到伤害时单位卡抖动并变红 0.9 秒；多段命中重新触发。每个角色或 Boss 行动完成后，推进下一行动或开放下一次操作前等待 1 秒；此等待不改变结算顺序或数值。

## 6. 明确不在当前规格内

- 挑战模式的角色限制、关卡/Boss 选择、奖励、进度和解锁；仅其入口提示行为已确定。
- Boss 选择界面的属性、技能、推荐队伍、难度与生命类型标记。
- 其他 Boss、多个敌人、召唤物、狂暴、难度、奖励、固定站位及 Boss AI 选择规则。
- 角色成长、装备、职业、稀有度、冷却、组合技能与推荐站位。

## 7. 规格约束

不得以旧规格、当前代码或 UI 推定上述未定内容。角色和 Boss 专属规则覆盖通用规则；训练模式例外覆盖普通战斗的失败处理。

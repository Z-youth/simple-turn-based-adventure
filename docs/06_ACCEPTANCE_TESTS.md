E06【自动】多段攻击每段分别计算、分别暴击、分别取整。

E08【自动】暴击率 130% 时实际必定暴击，属性仍保留 130%，溢出值可读取为 30%。

E10【自动】技能内普通固定伤害进入普通伤害公式，和额外伤害类型分离。

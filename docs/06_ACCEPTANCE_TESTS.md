# 规则验收项

## A. 流程与训练模式

- [ ] 流程固定为初始界面 -> 模式选择 -> 角色与站位配置 -> 选择 1 名 Boss -> 正式战斗。
- [ ] 训练模式可选全部已开放角色和 Boss；队伍为 1 至 4 名，角色与站位均不可重复，角色与站位在同一页面配置。
- [ ] 正式选择内容包含王大海、严岩、李木头、流年，以及训练假人与万夫长；选择万夫长代表进入其多阶段战斗，不把阶段主体列为独立 Boss。
- [ ] 初始界面退出需要二次确认；确认后停留在初始界面。挑战模式点击只显示“开发中，不要再点啦！”1.5 秒，不进入后续配置或战斗。
- [ ] 有限生命 Boss 被击败时结束训练；无限生命 Boss 不会因受到伤害而被击败。
- [ ] 训练模式全员死亡时不产生普通失败：立即暂停、展示本次战斗数据，Boss 不再行动。
- [ ] 全员死亡自动暂停时不提供继续游戏；重置恢复所有战斗状态并保留队伍、站位、Boss 后立即开始。
- [ ] 主动退出暂停并确认，确认后返回模式选择。
- [ ] 有限生命 Boss 击败与暂停菜单“结束战斗”均进入结果页，结果页显示行动序列数、每序列总伤害、各角色总伤害/承伤/护盾/治疗，并可重新开始或退出。

## B. 行动序列、触发与持续时间

- [ ] 每个行动序列开始按当前速度重排；排序后的速度变化只影响下一序列。
- [ ] 同速时玩家优先敌方，玩家按前1、前2、后1、后2，敌方按登场先后。
- [ ] 行动、个人回合、行动序列分别计数；主动结束回合不计入行动但会执行回合结束。
- [ ] 计入行动的技能完整结算后依次结算自身被动、体系共通、技能行动后、其他行动后，再判断结束回合。
- [ ] 同一时点默认自身被动 -> 体系共通 -> 其他效果按获得时间；专属顺序覆盖默认顺序。
- [ ] 新触发插入并深度优先结算完整触发链，再返回原效果后续内容；同阶段普通触发按获得时间，记录/锁定值不被实时状态覆盖。
- [ ] 持续 N 回合按持有者回合结束计数：自身回合内获得时当前回合算第 1 次，回合外获得时下个自身回合算第 1 次；先参与第 N 次回合结束效果再到期。
- [ ] 额外回合为完整回合且可继续产生；跳过回合不触发开始、行动、结束；中途入场/复活下序列再入队。
- [ ] 召唤获得即时个人回合时完整触发回合生命周期，但仍只从下一行动序列加入正常速度排序。

## C. 资源、伤害和多段攻击

- [ ] 手动技能任一资源不足即禁用；支付顺序严格为检查 -> 预留 -> 完整结算 -> 实际支付。
- [ ] 被免除、阻止或未发生的消耗不触发“消耗资源时”；设定能量不是获得/消耗。
- [ ] 预留资源在技能结算中不可被其他效果消费；固定目标在后续新行动开始前死亡、离场或被替换时取消，不默认重选。
- [ ] 普通伤害依次经过基础伤害、暴击、增伤、减伤、保留 1 位小数、护盾和生命。
- [ ] 同名增/减伤同乘区相加，不同名乘区相乘；任一减伤乘区达到 100% 时结果为 0。
- [ ] 额外伤害不算攻击、不能暴击、无视护盾、不受普通增减伤；触发攻击已使目标移除时，尚未结算的依附额外伤害取消。
- [ ] 特殊伤害默认先扣护盾；只按具体技能说明判定暴击与增减伤。
- [ ] “伤害 N 次”是 N 次独立攻击，逐次暴击和触发；单体目标中途移除停止余段，随机目标逐段重选存活合法目标。

## D. 护盾、状态、死亡和站位

- [ ] 有限生命单位护盾累计最高为最大生命 2 倍；无限生命单位不受该上限。
- [ ] 达到护盾上限时“获得护盾”动作仍可触发相关效果，除非效果要求实际增加。
- [ ] 普通/特殊伤害先扣护盾；治疗默认不超过最大生命。
- [ ] 前1仅保护后1、前2仅保护后2；对应前排存在时后排获得普通减伤乘区的 50% 减伤，离场立即失去。
- [ ] 同名状态可叠加，净化优先最早可净化层；特殊状态不能被普通驱散，除非明确点名。
- [ ] 单位生命降为 0 后移除；若在自身技能内死亡，技能完整结算后移除，且不再结算自身行动后/回合结束；队列空位直接跳过。

## E. 体系规则

- [ ] 势每层加 1 攻，势带来的攻击加成最高为原攻击力 2 倍。
- [ ] 回合开始达到势攻击加成上限时，每完整 10 层势获得 1 层势压；每层势压获得 5 点体系共通护盾。
- [ ] 势压攻击时每层造成 3 点额外伤害，每技能最多首次攻击触发一次；首次为群攻时每个目标各触发一次；回合结束清空势压。
- [ ] 持有意时暴击率仅加 30% 一次，回合结束减 1 层；计入行动后仍持有意时进行 50% 概率回 1 能量。
- [ ] 法无通用被动，只能按对应角色技能消耗强化。

## F. 王大海

- [ ] 回合开始少于 10 势得 2 能量，不少于 10 势锁定回合结束无消耗万江归海，并重置叠浪式 x。
- [ ] 每次行动开始的起势先加 1 势、净化 1 层可净化 debuff；无任意 debuff 时加 2 攻至回合结束且可叠加。
- [ ] 新潮式低势条件在起势前锁定；叠浪式支付 1 能量、不结束回合、首次后锁定本回合其他技能，并按 2/4/6/6... 获得势。
- [ ] 行动后势不少于 10 时，万江归海最多自动释放一次且不计入行动；海潮存在时满足门槛但不实际消耗势。
- [ ] 月海潮生支付 5 能量、不结束回合、获得持续 2 回合的 20% 暴击和 50% 暴伤及 2 层海潮。
- [ ] 回合结束严格为锁定的万江归海 -> 海潮减层 -> 清空势压 -> 其他回合结束效果。

## G. 严岩

- [ ] 守势在每个技能最多一次的受到攻击时获得 2 势，0 伤害/护盾全吸收也触发。
- [ ] 不动如山只由严岩自身技能/被动护盾或主动实际消耗势触发；势压与队友护盾不递归触发。
- [ ] 镇山岳按能量、势、伤害、自身护盾的顺序结算，并给队友护盾。
- [ ] 峰峦起使严岩获 1 次护盾，其他队友各获 2 次；层峦叠嶂完整结算后才实际支付 1 能量和 5 势，并按支付前势给队友护盾。
- [ ] 拜岳凿天预留全部势 S；第一段按普通伤害，第二段用支付前护盾对每个敌人造成不暴击但受普通增减伤的特殊伤害；支付 S 后触发不动如山，下回合势压前恢复 S 一半。

## H. 李木头

- [ ] 每个回合开始固定为微势减 2（最低 0）-> 势压 -> 其他回合开始效果。
- [ ] 微势在不多于 8、9 至 15、大于 15 势时分别采用正确的实际/视作层数与攻击加成；势压前置仍要求势攻击加成到上限。
- [ ] 春华和秋实同一时点只触发最早层，剩余层按后续时点逐层触发；春华使用新统计窗口。
- [ ] 刀域开启支付 2 能量、不结束回合但计入行动且不可重复开启；每次攻击在扣除预留消耗后的可用能量大于 0 时才触发额外伤害并立刻消耗 1 能量。
- [ ] 千山落木使用当前能量 x 进行 x 次普通攻击；刀域额外伤害最多触发 6 次且不耗能，完整结算后势设为 6、能量设为 2。

## I. 训练假人

- [ ] 训练假人为无限生命、攻击 5、速度 1 的势单位；伤害正常显示但不减少生命，免疫直接死亡和设生命为 0，护盾无上限。
- [ ] 回合开始严格为坚守获得 20 护盾 -> 气势获得 5 势 -> 其余体系结算；不能把势压放在气势之前。
- [ ] 报复从当前存活玩家中随机选 1 名，按气势生效后的当前攻击力造成 1 倍普通伤害，计入行动并结束回合。

## J. 界面、事件与结果页

- [ ] 战场保持战前固定站位和空位；单位默认卡与悬停详情分别显示规定的基础信息和实时详细数据，专属变量不串给其他角色。
- [ ] 技能详情的资源、倍率、段数、护盾/治疗、状态、目标与条件均与真实规则一致；有限生命单位护盾外壳按“当前护盾/(最大生命×2)”显示，无限生命单位不显示该外壳。
- [ ] 事件窗口仅显示真实行动与独立触发；同一行动合并、不同来源不合并，名称/来源/目标均取自原始事件。
- [ ] 状态到期、减层、临时属性倒计时、资源直接设置、势压重置等内部事件不进入事件窗口；势压仅在实际额外伤害存在时显示一条含伤害的记录。
- [ ] 真实伤害反馈持续 0.9 秒，多段伤害重新触发；每个角色或 Boss 行动完成后等待 1 秒再推进下一行动或开放操作，且不改变结算。

## K. 流年

- [ ] 战斗开始得 6 借来势；借来势不加攻击但参与层数比较、18 层阈值、技能读取、交换和势压，失去/转移时优先消耗且不能恢复。
- [ ] 正常势每层只加 0.5 攻，至少 40 正常势才达到 +20 攻上限；达到后势压使用包含借来势的总层数。
- [ ] 流年总势不多于 18 时，每次队友获得势事件只作一次 50% 判定；大于 18 时，每次流年获得势事件使所有流转队友各得 1 势；递归事件按实时层数与深度优先链完成且不死循环。
- [ ] 堪舆只允许势大于其他所有队友且不高于流年的敌人；势减半不可叠加、可净化、刷新 1 回合持续，底层势照常变化并在结束时恢复实时底层值。
- [ ] 定穴按 1 能量、2 势、1 流、0.6 倍伤害顺序；三生流转支付 1 能量、不结束回合、已开启禁用并替换一技能。
- [ ] 流年回合结束按自身流转层数扣流，流归 0 关闭领域；关闭、死亡或离场清空全场流转，死亡/离场还清空未触发的下一己方回合队列。
- [ ] 生生流变支付 1 能量、不结束回合；同目标叠加，换目标时只清旧目标流转、不清流年自身，再给双方各 1 层。
- [ ] 流转交换在其他回合开始效果结束后、决定行动前强制发生；双方二选一按实际失去势转移，优先消耗借来势；无另一持有者时跳过。
- [ ] 北山风起每次完整产生 3 势、3 流、0.6 倍伤害、条件势减半和 1 项队列；每个己方个人回合最多消费 1 项，额外行动不消费。
- [ ] 北山风起以 `20% + 流转层数×10%`、封顶 100% 判定，固定原目标，总计最多 3 次；每次是新行动，目标失效时取消所有未开始重复且不换目标。
- [ ] 南阳水来支付 1 能量并治疗其他角色 0.5 倍流年当前攻击；目标有流转时流年按计算值同疗且目标获得等于自身流转层数的势。

## L. 万夫长一阶段

- [ ] 骸骨将军为 600 生命、40 原攻击、95 速度、3 初始能量；每目标每次攻击判定得 3 势，普通伤害忽略玩家后排减伤，尸卒不继承。
- [ ] 死躯每序列最多实际失去 240 生命，护盾吸收不计；达到上限后生命不再减少但仍受到攻击，并免疫势压伤害。
- [ ] 偶数序列每次计入行动后，白骨银枪永久增加当时势层数的攻击；万夫长不享受，新骸骨将军继承且原攻击仍为 40。
- [ ] 行动技能1先得 1 能量再全体 0.8 倍伤害并计入行动；行动后满足能量≥3且尸卒<5时，技能2支付 3 能量召唤 1 尸卒且不计行动。
- [ ] 同场尸卒最多 5；新尸卒在骸骨将军完整回合后立即获得完整回合，并从下一序列按速度正常入队。
- [ ] 骸骨将军归零不死亡、不胜利；当前行动、行动后与触发链完成后清尸卒并转换。转换优先于尚未开始的新行动，固定目标失效，万夫长不继承队列位置。
- [ ] 进入二阶段演出总计 2 秒，0.3/0.5/0.2/四次各 0.2/最后 0.2 秒顺序正确；前三段按本次目标生命 25%～30%，末段补足目标生命。
- [ ] 尸卒为 200 生命、20 攻、60 速；n 初始 0、每自身回合结束 +1，前排优先随机，伤害为 `攻击×(1+0.5n)`，转二阶段全部清除。

## M. 万夫长二阶段与王骑

- [ ] 万夫长为 1000 最大生命、60 原攻击、105 速度；首次进入生命 1000/盾 0/势 0，再次恢复生命、盾、势、阈值记录，并追加进入前骸骨将军的势。
- [ ] 群体挑杀次数、破军三行动计数、二阶段总行动次数和三回合计数不跨阶段；阈值记录跨阶段。
- [ ] 最终暴击率恒定 50%、暴伤 200%（暴击 3 倍）；每次行动后固定 50% 额外行动且可连续，额外行动不触发回合开始/势压/三回合计数。
- [ ] 同序列首个普通行动无临时攻击；每次额外行动开始前累计 +30 攻，序列结束全部清除。
- [ ] 生命首次低于 750/500/250 时，跨阈值行动后按序获得已损生命 0.2/0.4/0.5 倍护盾和对应群体挑杀次数；一次跨多档全部结算。
- [ ] 挑杀每次普通/额外行动释放，默认随机单体 0.8 倍；有强化次数时改全体并消费 1 次，余次保留到后续挑杀但退出二阶段清除。
- [ ] 每完成 3 次万夫长行动只准备破军；下一行动前释放。额外行动先拿 +30 再破军；伤害为 `当前攻击×0.1×本次二阶段已完成总行动数`，破军不计行动。
- [ ] 每次万夫长行动后严格按阈值 → 上王骑冲阵 → 下王骑冲阵 → 额外行动判定；整条触发链结束后才能开始新额外行动。
- [ ] 第 3 个完整个人回合及回合结束效果完成后退一阶段，额外行动不计；1 秒演出按 0.2/0.5/0.3 秒，骸骨将军恢复 600 生命、3 能量并继承白骨银枪。
- [ ] 首次二阶段只召唤上下各 1 名 450 生命、35 攻、100 速王骑，此后不补充；存活王骑退场保存并恢复，死亡王骑永久死亡。
- [ ] 两王骑近卫时万夫长/上/下分别承受 50%/25%/25%，单骑时 75%/25%；在护盾减伤前拆分，适用普通和可分摊特殊伤害，不分摊额外伤害。
- [ ] 王骑游骑枪术随机单体 1 倍并计行动；冲阵在万夫长行动后群体 0.5 倍、计王骑行动且不影响正常回合；每次计入行动后永久 +3 速度，下序列生效。
- [ ] 万夫长归零优先于三回合退场；完成当前技能和直接死亡效果后，存活王骑同时死亡并立即胜利，不再触发行动后、回合结束、延迟或额外行动。

## N. 未定项处理

- [ ] 验收不得要求挑战模式后续流程、Boss 选择展示字段、特殊伤害统一通则、其他训练/挑战 Boss、角色养成或未经确认的多 Boss 编成。
- [ ] 验收不得把同一时点且获得时间完全相同、无法区分的普通触发先后当作既定规则。

# 规格实施约束

## 1. 文档用途

本文件只把已确定规格转换为实施依赖与验证边界，不新增玩法规则，也不替代 `00` 至 `04` 的规则正文。已由《游戏流程》明确的界面、暂停、结果页与事件窗口要求属于现行规则，不得再标为未定。

## 2. 实施顺序

1. 战斗状态：单位变量、站位、存活/移除、行动序列、个人回合、行动与暂停状态。
2. 通用结算：触发顺序、持续状态、资源检查/预留/完整结算/实际支付、普通/额外/特殊伤害、护盾、死亡与移除。
3. 体系规则：势、势压、意、法及特殊状态的普通驱散限制。
4. 内容规则：王大海、严岩、李木头、训练假人。
5. 训练流程：有限/无限生命 Boss、全员死亡暂停、数据展示入口、重置、主动退出确认。
6. 已确定的界面与信息显示；未定界面字段不得臆测。

## 3. 不可改变的实现约束

- 结算必须区分行动、个人回合和行动序列。
- 每个触发点默认是自身被动 -> 体系共通 -> 其他效果；训练假人回合开始固定为坚守 -> 气势 -> 其余体系结算。
- 资源支付不可在技能效果前直接扣除，必须落实检查 -> 预留 -> 完整结算 -> 实际支付。
- 有限生命单位护盾上限为最大生命 2 倍；无限生命单位没有该上限。
- 额外伤害与特殊伤害不可按同一类别处理；死亡移除会取消依附于已移除目标的未结算额外伤害。
- 全员死亡的训练分支是暂停和数据展示，不是普通失败；暂停后只可重置或退出。
- 严岩、李木头是正式内容，不能因当前未实现从数据或验收中删除。

## 4. 实施前必须保留的未定项

不得实现或验收挑战模式的后续配置/战斗、Boss 选择显示字段、特殊伤害统一通则、回合外持续状态计时、额外 Boss/敌人和角色养成。1 至 4 人队伍、站位唯一性、选择页返回、退出确认取消后保持暂停、暂停日志/返回战场、结果页统计字段及有限生命训练结束去向均已明确，必须服从 `01` 与 `02`。

## 5. 验收依据

功能验收以 `06_ACCEPTANCE_TESTS.md` 为准；每项仅验证已确定规则。界面展示只验证已明示的信息要求，不将未定布局、按钮、字段或操作视为缺陷。
